# Authorized use only

Alsayf is intended strictly for authorized security testing and administration.
Use it only on systems you own or for which you have explicit permission, and
stay within the agreed scope. Operators are responsible for their actions and
for complying with applicable laws, contracts, and organizational policies.

Alsayf is a toolkit built for personal convenience in these authorized tasks.
It is not intended for red team operations. OPSEC, stealth, and detection evasion
are outside the project's scope. Expect its binaries, execution, network traffic,
downloads, and build activity to be visible to and detectable by security
monitoring and endpoint protection systems.

The software is provided "AS IS", without warranties of any kind. The authors
and contributors accept no responsibility for misuse, unauthorized activity,
or damage arising from its use, to the extent permitted by applicable law.

# Third-party components

- [Cobra](https://github.com/spf13/cobra): command hierarchy, help output, argument validation, and command execution.
- [pflag](https://github.com/spf13/pflag): command-line flag parsing through Cobra.
- [mousetrap](https://github.com/inconshreveable/mousetrap): Windows shell-launch detection through Cobra.
